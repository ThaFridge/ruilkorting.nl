# Deal Engine

## Deal definition

A deal can be:
- train deal
- train + activity
- train + wellness
- train + event
- train + hotel
- complete day trip
- weekend package

## Deal score

Possible factors:
- discount
- absolute price
- relevance
- validity
- season
- popularity
- travel effort
- provider reliability

Affiliate commission must not automatically determine objective deal quality.

## Expiration

Deals must have validity and should automatically leave active results when expired.
