# UX Guidelines

## Mobile-first

Primary experience:
1. enter departure point
2. choose date
3. choose budget
4. optionally choose category/max travel time
5. discover results
6. compare
7. open destination
8. click relevant offer

## Homepage

Use a combination of:
- dominant search
- seasonal inspiration
- category navigation

Search remains dominant.

## Categories

Examples:
- Treindeals
- Steden
- Festivals
- Evenementen
- Pretparken
- Wellness
- Kerstmarkten
- Buitenland
- Weekendjes weg

## Data freshness

Every result and price shows when it was computed/retrieved ("reistijd berekend voor za 10 okt", "prijs van 3 okt"). Travel times link to a live planner for the actual journey.

## Performance

Mobile-first budgets: homepage ≤ 100 KB JS, search island loads station index first and only one reachability file per chosen station. Pages render fully without JavaScript except the search/filter interactions.

## Result cards

Show useful decision information:
- destination
- activity
- travel time
- route summary
- price status
- deal indicator
- seasonal relevance

Avoid clutter.

## Accessibility

Use semantic HTML, keyboard support, adequate touch targets and clear focus states.
