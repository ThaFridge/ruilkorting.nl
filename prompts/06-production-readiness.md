# Production Readiness

Perform a release review covering:
- tests
- security
- performance
- content/data schema validation
- scheduled pipeline health
- site size and build time budgets
- GitHub Pages settings (Actions source, custom domain, HTTPS)
- Cloudflare Pages fallback tested once
- monitoring (build failures, bandwidth)
- SEO
- mobile UX
- error handling
- rate limits
- external provider failures

Do not mark production-ready if critical unknowns remain.
